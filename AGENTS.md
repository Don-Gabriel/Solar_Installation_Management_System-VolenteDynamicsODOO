# Project working instructions

## Ruflo integration

When working on multi-file tasks or complex features, use ToolSearch to find and invoke ruflo MCP tools. Key tools: memory_store, memory_search, hooks_route, swarm_init, agent_spawn. Check system-reminder tags for [INTELLIGENCE] pattern suggestions before starting work.

Use only tools actually exposed by the host. If Ruflo/ToolSearch is unavailable, report that once and continue with ordinary repository tools. Do not claim that a swarm, memory store or Claude model ran when it did not.

- Maintain genuine small commits. Keep secrets, runtime files, local PDFs and machine-specific research inventories out of Git.

- Only mark a milestone complete after its observable gate passes. Report actual checks and remaining limitations.
