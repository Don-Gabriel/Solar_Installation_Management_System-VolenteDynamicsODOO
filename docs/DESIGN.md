# Interface direction

SunPower is a working solar operations desk. The distinctive element is a continuous installation lifecycle that shows what is ready, blocked and completed, with serial provenance accessible from the same customer record.

- Ink #132e3b: navigation and primary text.
- Paper #f5f6f8: workspace background; white #ffffff for work surfaces.
- Solar #f7bd42: primary highlights against dark ink.
- Evergreen #176648: completed/healthy status; alert #a13a29 for failures.
- Muted #596b75 for secondary information.

Manrope provides compact, confident headings; DM Sans provides readable forms and operational tables. Both are locally bundled. Numbers use tabular figures. Left aligned labels, restrained separators and generous outer margins establish hierarchy.

Desktop: persistent narrow navigation → heading/actions → lifecycle or operational summary → worktable with contextual side panel. Mobile: compact navigation → one-column work cards → detail → focused action. The technician's core navigation stays reachable at the bottom.

Review against the brief: use a real pipeline and exception queue instead of a decorative marketing hero. Asset passport and installation evidence carry the solar-specific identity. Avoid gratuitous charts and motion. Controls have visible focus and phone-sized targets; status always includes words. Cache static assets only.
